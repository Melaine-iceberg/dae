Attribution for sarasa-term-sc-nerd-{regular,bold}.woff2
========================================================

These two faces are a subset of

    Sarasa Term SC Nerd — Sarasa v1.0.27, ttfautohint v1.8.4, Nerds 3.3.0
    https://github.com/laishulu/Sarasa-Term-SC-Nerd

which is 'Sarasa Term SC' patched with the Nerd Fonts icon sets listed below.
They were subset with HarfBuzz to the codepoints this application ships
(scripts/build-mono-font.py). No outline, advance, hinting program or name
record was altered, and the upstream family name is kept, so no Reserved Font
Name is claimed or reused by this project.

The Sarasa licence — SIL Open Font License 1.1, covering Iosevka, Source Han
Sans and the Inter portions — ships beside this file as
LICENSE-Sarasa-Gothic.txt, and is installed with the application under
licenses/ (see src-tauri/tauri.conf.json). Each face also carries the upstream

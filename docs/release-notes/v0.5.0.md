# dae v0.5.0

界面整体重建为 **Atlas** 设计语言，Linux 补上系统深浅色跟随，并把这一轮性能工程真正落进发版二进制 —— 这是 0.4.0 以来最大的一次改动，累计 72 个提交。

---

## 这一版最该先知道的三件事

1. **界面换了骨架。** 上一版的 Quiet Desk 方向被 Atlas 取代：窗口分三层色阶（frame / paper / canvas）、只有一行命令栏、只保留一个强调色。工具栏从两行压成一行，导航栏不再是一块面板而是窗口的边框本身。
2. **Linux 的产物开始带 PGO 与 BOLT。** 这不是配置改动，而是修掉了一条从上线起就没生效的链路 —— 之前 Linux 上两级优化从未真正跑通。
3. **SFTP 不再无条件信任主机。** 旧实现接受任何主机密钥，一个能挡在服务器前面的中间人就能拿到密码和整棵目录树。

## 界面

### Atlas 设计语言

- 窗口分三级色调：**frame**（标签条 + 边距 + 导轨）、**paper**、**canvas**。标签条与导轨同色，标签之间的分隔线随之取消。
- 命令栏收为单行：跳转按钮组 → 路径胶囊（作为主轴）→ 自适应搜索框 → 操作、视图控制、面板开关。
- 搜索框在窗口宽度低于 **1360px** 时折叠成仅剩放大镜的按钮。
- 导轨从"面板"变成"边框"，行高 30px，当前行直接取用强调色。
- 面包屑提到工具栏上方独立成行，祖先图标变淡；空状态换成带色块的地块。

### 列表与网格

- 表头 30px 吸顶，11px 大写字重、字距 +0.07em，悬停只给标签着色。
- 行高 **28 / 34 / 44** 三档，文件名 13px，时间与大小改用等宽字体，行间只留一条 `--border-soft` 细线（选中时取消）。
- 网格单元格有自己的静息地块与缩略图槽，12px 圆角。

### 其他构件

- **Inspector 成为窗口的第三列**（300px），不再是浮层。
- **状态条移到终端抽屉下方**，26px，报的是机器状态而非文件夹状态：模式点、条目数、选中数、当前卷剩余空间（按最长挂载点匹配）。条目数不再重复显示两遍。
- 命令面板 660px、12vh 起始高度；操作岛改为带内嵌高光的模糊胶囊；终端改为抽屉（顶部细线 + 弱化填充），不再是一张独立的卡片。
- **图标统一为 Solar `linear`**：单一 1.5px 描边、跟随 `currentColor`。双色调那一对和配套的 `.type-glyph` 页型着色一并移除 —— 现在一种颜色只承载一种含义。
- **圆角收束为四档**：4px（微型目标）/ 6px（控件与行）/ 12px（菜单、卡片、浮层）/ 16px（对话框、命令面板、内容面板）。此前散落的 9px 按钮、8px 输入框、5px 下拉与 `rounded-2xl` 覆盖全部清理。
- 应用图标换成带圆角的位图稿。
- 对话框默认**不再有入场动画**，也不再压暗身后窗口。

## 系统主题

- **Linux 新增原生读取**：直接向 GTK 取深浅色偏好并监听变化，前端通过新事件 `system-theme-changed` 订阅。此前 Linux 上这条路径是缺的。
- **Windows / macOS 无需新增读取器**：WebView2 与 WKWebView 会如实通过 `prefers-color-scheme` 汇报系统外观，前端本就会跟随。这一点在代码里被显式写明，免得后来者以为漏了一块。
- 系统强调色继续参与整套外壳的着色。

## 性能

### 发版构建：两级 PGO + Linux LLVM BOLT

release profile 原本已有 `lto = "fat"`、`codegen-units = 1` 与 mimalloc，剩下两个杠杆是轮廓引导优化与后链接优化。这一版把两条都接进了发版流程：

| 平台 | PGO 采集 | BOLT |
|---|---|---|
| Windows | 20.0 MiB，63,869 个函数 | 不适用（改写 ELF） |
| macOS | 14.5 MiB，41,377 个函数 | 不适用 |
| Linux | **28.1 MiB，94,462 个函数** | ✅ 见下 |

Linux 的 BOLT 实测（本次构建）：

| 指标 | 结果 |
|---|---|
| 拿到轮廓的函数 | 2,068 / 17,713（**11.7%**，插桩时为 0%） |
| 布局被重排的函数 | 1,590（占已采样函数的 76.89%） |
| 执行指令数 | 23,215,829 → 23,058,761（**−0.7%**） |
| 无条件分支 | **−37.0%** |
| 向后分支 | −12.8% |

需要说明的是：**优化是可降级的**。构建机没有可用 GUI 会话、缺 `llvm-bolt`、或拿不到 profile 时，发版会自动退回普通 release 构建，不会阻塞发布。降级路径与判定方法写在 `docs/pgo-bolt.md`。

### 冷启动

先做了归因，再改。`DAE_STARTUP_PERF=1` 会记录一条从 `run()` 到首帧的完整时间线，结论与此前的猜想不同：

| 阶段 | 占比 | 绝对耗时 |
|---|---|---|
| WebView2 建窗口 | 63–65% | 270–309 ms |
| React 首次 commit | 14–16% | 62–74 ms |
| JS 解析 + 执行 | 3–4% | 15–18 ms |

真正的浪费是 `takeTabHandoff`：在 `createRoot` 之前等一次 IPC 往返，新 webview 上要 **20–26 ms**。现在 Rust 通过 `initialization_script` 直接注入 `window.__DAE_TAB_HANDOFF`，前端同步读取：

```
boot-eval-end → render    19.7–28.0 ms  →  3.9–4.5 ms
```

两个看起来可行的方案被实测否掉了，理由与数据都留在决策记录里：

- **由 Rust 渲染首屏** —— 不可行。18 次骨架实验里 0 次在 bundle 求值完成前产生画面，窗口从创建到 React 首帧一直是空白。启动是一整块连续的主线程工作。
- **把首屏 JS 搬到 Rust** —— 收益接近零。React 渲染只占 62–74 ms 中的 19 ms，剩下的约 40 ms 是文档首次样式与布局（React 插入树后，标签胶囊触发的那次测量），其中至少 19 ms 是中文字体首次启用。预热比省下的更多。

### 目录与后台查询

| 场景 | 之前 | 现在 |
|---|---|---|
| Git 分支列表（1,000 分支） | 83.1–83.6 ms | **5.6–6.2 ms** |
| Git 目录状态（20,000 文件工作区，单目录） | 33.6–35.9 ms | 一次 O(工作区) 扫描，5 秒复用窗口 |
| 同一工作区连续浏览 5 个目录 | ~173 ms | 同一份扫描结果 |

- 分支列表的瓶颈不是遍历，而是每个分支都调一次 `git_repository_head()`。现在 HEAD 的符号目标只读一次，逐分支比对。
- 目录状态把"扫描"与"过滤"拆开：`scan_worktree_status` 是 O(工作区)，`derive_directory_status` 是 O(记录数)，缓存按 watcher 变更计数 + 索引 (mtime, length) + HEAD 目标失效。
- 内容搜索：walk 线程原先为**每个文件**新建一个 `Searcher`，现在每线程复用一个。
- 预览：最后一个等待者直接取走响应而不是再克隆一份，无重复请求时图像拷贝从两次降到一次。
- Windows 目录枚举恢复了 `FindFirstFileExW` + `FIND_FIRST_EX_LARGE_FETCH` 批量路径。

## 安全

**SFTP 主机密钥校验**（`fix(sftp)`）—— 旧策略 `AcceptAnyHostKey` 对每次握手都答"是"。现在改用 OpenSSH 的 `accept-new` 语义，信任落在你自己的 `~/.ssh/known_hosts`：

- 首次连接记录 SHA-256 指纹；
- 指纹变化是**硬拒绝**，不是警告 —— 报错同时给出两个指纹、文件与行号，以及修复用的 `ssh-keygen -R`；
- 已在记录中的主机若出示文件未固定的密钥类型，同样拒绝，而不是追加第二行（换算法是绕过固定密钥的廉价手段）；
- 密钥无法写入（只读 home、无 home）时拒绝连接，而不是退回信任。

选择复用它而不是自建存储，是因为**信任属于这台机器，不属于某个应用**：你此前用 `ssh` 接受过、或用 `ssh-keyscan` 固定过的主机可以直接连上，文件也仍然可以用 `ssh-keygen -F/-R` 审计与修复。

## 修复

- 标签撕离时，IPC 处理器返回之前就构建新窗口导致的竞态。
- 标签条空白区域现在可以拖动窗口。
- 窗口背景材质不再渗进文档层。
- 预览面板不再闪出窗口底色。
- 对话框打开时不再压暗背景，也不再淡入（属性、打开方式等）。
- macOS 的 `window_material` 跟随模块重构修正 `include_str` 路径。
- 清掉 UI/UX 审计的六项问题与四项类型化 lint 发现。
- 新标签按钮移入标签行，取消其下方的凹槽。

## 仍需注意

- **首次冷启动的首帧仍受限于 WebView2 建窗口（270–309 ms）**，这一版没有改动它。剩余的优化项是常驻预热窗口，属产品决策而非工程问题。
- **Linux 的 PGO/BOLT 依赖构建机有可用 GUI 会话**。本次发版已验证生效；若该条件不满足，产物会自动退回普通 release 构建，功能不受影响。
- dae 仍在 0.x，`settings.toml` 的字段与快捷键绑定格式仍可能变化。

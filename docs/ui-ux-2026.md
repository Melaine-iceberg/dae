# dae 界面规范（Qt 版，2026）

设计对象是 `qml/` 下的 41 个文件、19652 行，以及它要取代的 React 版视觉遗产
（`src/App.css`）。所有数字都是可实现的，不是示意图。

本文的取舍只有一条判据：**文件管理器的每一次操作都有明确的下一步，界面不该让人
找下一步在哪。**

## 1. 现状测绘

先把现在真实的样子记下来，改动才有依据。

| 项 | 现状 | 位置 |
| --- | --- | --- |
| 纵向外壳 | 40 标题 + 34 标签 + 40 导航 + 22 状态 = **136 px** | `ShellWindow.qml` 的 `body.height` 表达式 |
| 侧栏 | 198 / 0 | `ShellWindow.qml:2225` |
| 预览 | 300 / 0 | `ShellWindow.qml:2591` |
| 搜索框 | 常驻 224，占导航条 1/4 | `ShellWindow.qml:2086` |
| 行高 | 28 / 34 / 44，表头 32 | `FileList.qml:37-39` |
| 字号 | 9、10、11、12、13 | 全仓 200+ 处 `font.pixelSize` |
| 圆角 | 4、5、6、7、12 | 全仓散落 |
| 颜色 | 每个文件自己写一份 `textColor` / `mutedColor` / `hairline` | `TitleBar.qml:24-28`、`ShellWindow.qml:267-274`、`FileList.qml:48-50`…… |
| 控件 | 纯 `QtQuick` 图元，不用 Qt Quick Controls | 41 个文件只 import `QtQuick` |

四道横条各有自己的底色，读者看不出哪一条归谁管；这是"看起来像原型"的
主要原因，不是配色。

### 1.1 六个必须先修的硬问题

不是审美问题，是功能或平台问题。

1. **没有导航历史。** 全仓搜不到 back / forward 栈，导航条只有"侧栏开关"和
   "上一级"。`Alt+Left`、`Alt+Right`、`Backspace` 都没有绑定。文件管理器没有
   后退键，用户只能靠侧栏重走一遍。
2. **窗口按钮在 macOS / Linux 上是豆腐块。** `TitleBar.qml:101` 写死
   `font.family: "Segoe Fluent Icons"`，Mac 没这字体，三个按钮渲染成缺字方格。
3. **等宽字体写死 Cascadia Mono，14 处**（`ShellWindow.qml:2658`、`GitPanel`、
   `ContentResults`、`MediaPreview`……）。Cascadia 只随 Windows Terminal 分发，
   Mac/Linux 上会掉进不确定的回退字体，同一段状态文字在三平台三种宽度。
4. **图标有三个来源**：`ThemedIcon`（自绘）、unicode 字形（`\u2630`、`\u2191`，
   17 个文件）、Segoe Fluent Icons。同一个"关闭"在三个地方是三种画法，字号一变
   基线就错。
5. **字号下探到 9 px**（`FileList.qml:928`、`Sidebar.qml:430`、`Sidebar.qml:489`）。
   9 px 在 125% 缩放下是 11.25 逻辑像素，仍在可读线下，且随 HiDPI 抖动。
6. **行高 34 不是 2 的倍数**，和 32 的表头、28 的图标格对不齐，滚动时行线会错半像素。

## 2. 定位

**内容占满窗口，外壳只在被需要时出现。**

三条硬约束，用来否决任何后续提案：

1. 视线起点是第一行文件名，不是顶栏。纵向外壳 ≤ **116 px**。
2. 一个窗口只有一种饱和色：交互色。它不上背景、不上卡片、不上图标填充。
   类型图标的那六种分类色是例外，它们只在 16 px 的图标里出现。
3. 任何装饰必须能回答"它传达了什么状态"。答不上就删。

### 2.1 反面清单（这些会立刻把界面变成 2026 年的 AI 味）

- 玻璃拟态卡片、半透明面板叠半透明面板
- 紫色／靛蓝渐变当品牌色
- 24 px 大圆角药丸按钮、悬浮圆形主按钮
- 每个面板都带投影，形成三层阴影叠加
- 空目录里放插画
- 图标用 emoji 或双色填充
- 居中大标题 + 副标题的"欢迎"版式出现在工具软件里
- 行按 20 ms 错峰入场、骨架屏呼吸循环

## 3. 基础层

> 已落地：`qml/Theme.qml`（`pragma Singleton`，由 `qml/qmldir` 声明，
> `apps/dae/build.rs` 打进 qrc）。41 个文件的 894 处色值收敛到 59 处，
> 剩下的全部是有理由保留的语义色（见 §3.1 末尾）。

### 3.1 颜色

**八位十六进制在 Qt 里是 `#AARRGGBB`，不是 CSS 的 `#RRGGBBAA`。** 写成
`#ffffff14` 会得到一个接近不透明的黄色，而且不报错、只是画出来。半透明白
必须写 `#14ffffff`。这一条值得单独记住，我在迁移里踩过一次。

材质色只在窗口骨架（chrome）上；内容面**必须不透明**。现在 `chromeColor`
是半透明 tint 而列表是纯实色，两者相接处出现一条色阶断层——这就是为什么
顶栏看着"浮"在内容上。

- 交互色一屏最多出现 3 处（一个主按钮、一个展开的选中行、一个焦点环）。

- 斑马纹（`alternateColor`）删掉。用 4% hover 和 12% 选中区分层次，斑马纹在
  深色下会和选中行打架。

### 3.2 字体

系统 UI 字体（`Qt.application.font`），不要指定族名。等宽另立一个平台族栈：

| 平台 | UI | 等宽 |
| --- | --- | --- |
| Windows | Segoe UI Variable Text → Segoe UI | Cascadia Mono → Consolas |
| macOS | SF Pro Text | SF Mono → Menlo |
| Linux | 系统 sans（fontconfig） | JetBrains Mono → DejaVu Sans Mono |

字号阶梯沿用 React 版，两版要能被认成同一个产品：

| 角色 | 尺寸/字重 | 用途 |
| --- | --- | --- |
| `title` | 22 / 600 | 对话框标题、外观设置页标题 |
| `subtitle` | 15 / 600 | 区段标题（侧栏分组、设置分组） |
| `body` | 14 / 400 | 列表行、预览正文、设置项 |
| `label` | 13 / 520 | 按钮、菜单项、列头以外的控件文字 |
| `caption` | 12 / 400 | 列头、元数据、状态条次级 |
| `micro` | 11 / 520 | 徽标、计数、快捷键提示 |

- 11 px 是地板。禁止 9、10。
- 正文行高 1.45，标题 1.15。
- 数字列（大小、时间、计数、速率）加 `font.features: {"tnum": 1}`，右对齐。
  这是文件管理器里最容易被忽略、也最影响扫读的一处。
- 单屏字号不超过 4 档。

### 3.3 几何

间距只有 4 / 8 / 12 / 16 / 24 / 32。圆角只有四级，与 React 版同源：

| 级 | 值 | 用在 |
| --- | --- | --- |
| `xs` | 4 | 键帽、徽标、行内小目标 |
| `sm` | 6 | 行、按钮、输入框、菜单项、标签 |
| `md` | 12 | 菜单、浮层、toast、预览挂载面 |
| `lg` | 16 | 对话框、命令面板 |

当前散落的 5 / 7 是间距噪声，全部归到上面四级。

行高改为 **28 / 32 / 40**（紧凑 / 默认 / 宽松），表头 32。34 和 44 退出。
图标 16 px，绘制在 24 px 格子里（光学边距 4），列表行内与文字基线居中对齐。

点击目标最小 24×24；图标按钮的可点区域永远大于绘制区域。

### 3.4 材质与海拔

- 材质（Mica / Acrylic / vibrancy）只铺在 `chrome` 上；内容面永远实色。
- 海拔两级：内容面 0，浮层 1。浮层 = `raised` + `hairline-strong` 1px +
  阴影 `y2 blur12 8%`。面板不带投影，用 hairline 分隔。
- 全窗口只有一个"浮起来"的东西（菜单 / 对话框 / 命令面板之一）。

### 3.5 动效

| 动作 | 时长 | 曲线 |
| --- | --- | --- |
| hover / 选中 / 焦点 | 90–110 ms | OutQuad |
| 面板滑出、侧栏折叠 | 180 ms | OutCubic |
| 菜单、命令面板 | 160 ms（opacity + scale 0.97→1） | OutCubic |
| 视图切换（列表↔网格） | 200 ms，只动 opacity | OutCubic |

- 只动 `opacity` 与 `x/y`；不动 `width` / `height` / `anchors`（触发布局重算）。
- 禁止：列表行错峰入场、骨架屏呼吸以外的循环、按钮回弹。
- 新增 `ExplorerPrefs.reduceMotion`，开启后全部改为瞬时切换。Qt 6 没有系统级
  媒体查询，这个开关得自己上。当前缺失。

### 4.1 顶栏：标题与标签合并（44）

"dae" 这个标题对已经开着应用的人没有信息量，路径在导航条里，标签写的是目录名。
两行合并成一行，空白区就是拖窗区。

- **Windows**：三个按钮 46×44，悬停关闭 `#c42b1c`。`crates/dae-qt/cpp/window.h`
  里的 `kButtonDp = 46` 不变，`kTitleBarDp` 40 → 44。maximize 仍是
  `HTMAXBUTTON`，Snap Layouts 不受影响。标签条的空白区必须仍返回 `HTCAPTION`，
  否则撕标签时整个顶栏不能拖。
- **macOS**：红绿灯占左侧 78 px，标签从 x=86 起。不画自绘窗口按钮。顶栏
  双击行为交给系统。
- **Linux**：右上自绘三钮，风格与 Win 一致（GNOME/KDE 用户在 CSD 下预期如此）。
- **实现约束（已落地）**：标签条是顶栏里唯一必须保留为 client area 的一段。
  `window.h` 的命中测试把整条 44 当作 caption，只有 QML 通过
  `setCaptionClient(left, right)` 报上来的带区返回 `HTCLIENT`；否则点标签会变成
  拖窗口。改标签宽度/间距/起始位置时，这两处必须一起改。
- 「新窗口」按钮从标签条移走了 —— 它是这条 44 px 上唯一的空位，而空位是窗口的
  拖拽把手。同一个功能留在命令面板（`新建窗口`）。

标签：

- 高 34，居中在 44 内，间距 2，圆角 6。
- 激活标签 `raised` 底 + `hairline` 1px；非激活透明，hover 4%。
- 关闭按钮只在激活或 hover 时出现——每个标签省 16 px，10 个标签就是 160 px。
- 宽 120–220，按内容自适应，超出 ellipsis 中间截断（`~/code/…/qml`）。
- 新标签 `+` 紧贴最后一个标签，不靠右。
- 撕标签：拖动 12 px 触发，被拖标签 60% 不透明，插入位置画 2 px 竖线（`interactive`）。

### 4.2 导航条（46）

一条里按顺序：**后退 / 前进 / 上一级** · 面包屑（占满剩余）· 搜索按钮 · 视图切换。

- 后退/前进是本规范里唯一的新控件。**已落地**：栈挂在 `Tab.qml` 上而不是窗口上
  —— 标签就是浏览会话，撕裂到新窗口后后退键必须还在。两条栈各限 64 条，条目是
  `{ path, selected, anchor }`，所以回到历史位置时选中项也跟着回来。
  「新跳转清空前进栈」按浏览器语义处理；从一个面（回收站/空间/概览）跳进文件夹
  时不记栈，因为那时的 `listing.path` 已经不是用户看到的东西。
- `Alt+Left` 后退，`Alt+Right` 前进，`Alt+Up` / `Backspace` 上一级；macOS 用
  `Cmd+[` / `Cmd+]` / `Cmd+↑`。
- 前进/后退在栈空时**保留占位但降为 `hairline` 色**，不要隐藏——按钮位置跳动比
  按钮变灰更糟。鼠标侧键（`BackButton`/`ForwardButton`）还没接，是下一步。
- 面包屑每段 hover 4% wash，当前段不加粗（加粗会让路径条在移动时抖动）。
  超出用 `…` 开祖先菜单。点空白进入路径编辑（现有行为保留）。
- 搜索：从常驻 224 px 输入框改为图标按钮，点击展开为 240 px 输入框；有查询词时
  保持展开，`Esc` 清空并收回。`Ctrl+F` 直接展开。这条改动把导航条还给路径，
  也把"搜索"从背景噪音变回一个动作。
- 视图切换：单个按钮 + 菜单（列出/网格/分栏/概览），按钮图标显示当前视图。
  不做四段 seg control——Hick 定律，且窄窗口放不下。
- 内容搜索的选项条（`\u2022*` / `Aa` / 类型过滤）保留在导航条下方 30 px，
  只在内容搜索激活时出现，不做常驻。

### 4.3 状态条（26）

三段：左信息、中传输、右开关。

- 左：`N 项 · 已选 M 项` + 上下文（`搜索：resize · 12 项` / `回收站` / `sftp://host`）。
- 中：传输折叠成胶囊 `2 传输  ↻`，点击展开浮层列表（当前 `TransferQueue` 是
  独立面板，会挤压内容）。浮层每行：方向、文件名、进度条 3 px、速率、剩余、取消。
- 右：`main`（git 分支）、预览开关、终端开关。图标 16，激活态 `ink`，非激活
  `ink-faint`。
- 数字 `tnum`；等宽只用于协议名和速率。
- 现在状态文字是 `Cascadia Mono` 11 px —— 改为 UI 字体 12 px，只有 `sftp://`
  这类技术串用等宽。

### 4.4 侧栏（198 → 216）

198 放不下"新建空间"和长卷名。改 216，可拖 180–280，宽度记忆。

- 分组：`主目录 / 桌面 / 下载 / 文稿 / 图片` → `卷`（带 3 px 容量条）→
  `空间` → `网络`（WSL / SSH / SMB / 云）→ `回收站`。
- 行高 28，图标 16，缩进 14/级，展开箭头 12 px 且只在 hover 或展开时着色。
- 分组标题 11/520 `ink-faint`，大写间距 +0.02em，不折叠（文件管理器里折叠侧栏
  分组是给自己找麻烦）。
- 拖放目标：整行 `selection` wash + `hairline-strong`，不用描边框。
- 卷行右侧容量条：`3 px`，填充 `interactive` 40%，超过 90% 转 `warn`。

## 5. 内容区

### 5.1 列表（主视图）

- 行高 28/32/40，表头 32（12/520 `ink-faint`，排序指示 6 px 三角）。
- 列：名称（flex, min 220）/ 大小（右, 96）/ 类型（110）/ 修改时间（140）。
  窄于 360/470/550 依次丢列（现有 `showModified` 等逻辑保留）。
- 图标 16 在 24 格；缩略图 24（列表）/ 160（网格）。
- 选中：`selection` wash + 左侧 2 px `interactive` inset bar。
- 焦点：**只在键盘操作时**画 1 px `interactive` 内描边。鼠标点击只给选中态。
  这是"单击后行上出现一圈框"的根源，Qt 默认会给焦点框，要按输入原因过滤。
- hover 4%，不改变文字色。
- 内联重命名：选中行直接可编辑，默认只选中主名不含扩展名。
- 空目录：一行 13 px `ink-muted`（`这个文件夹是空的`）+ 两个文字动作
  （`新建文件夹`、`粘贴`），不画插画，不居中。
- 加载：只在超过 300 ms 时出 8 条 hairline 脉冲行，宽度固定（避免宽度随机导致
  的反复重排）。

### 5.2 网格

tile 112 / 144 / 176 随 pane 宽三档，缩略图 4:3，文件名常显两行 ellipsis。
网格下不显示大小和类型（进预览面板）。选中态与列表一致。

### 5.3 分栏（Miller columns）

列宽 240，末列 flex。每列 header 吸附，列间 1 px hairline。`←` / `→` 跨列移动
焦点并展开下一列。

### 5.4 预览面板

- 宽 300 / 360 / 440（按窗口 1180 / 1440 / 1800 断点），记忆，可拖 280–520。
- 单文件：头（32 图标 + 文件名 13/520 + 类型 11 `ink-muted`）→ 缩略图或文本 →
  元数据 4 行 → `全部属性 ⌄`（原地展开，不完全替代 `PropertiesDialog`）。
- 多选：`3 项 · 1.2 MB` + 类型分布前 3。
- 目录：前 20 项 + `还有 342 项`。
- 文本用等宽 12/1.5，行号默认关。
- 媒体黑底、不描边、不留安全边距（现在四周的 8 px 内衬让图片看起来更小）。

### 5.5 终端

底部 dock，高 40% 可拖，最小 120，标题栏 28（会话名 / 清屏 / 关闭）。
与预览面板可以并存——两个都是"看"的地方，互斥反而打断。

### 5.6 对话框

12 个对话框共用一套骨架：`lg` 圆角 16、宽 480（表单）/ 640（列表型）、
标题 `title` 22/600、正文 14、底部动作右对齐、主按钮唯一。

- 遮罩不用黑幕：`canvas` 12% 叠一层，上下文保留可见。
- 破坏性操作：主按钮 `danger` 色，文案动词化——`移到回收站`，不是`确定`。
- 覆盖冲突（`TransferConflictDialog`）：左旧右新并排，差异区高亮，
  `全部应用` 做成次要按钮加复选框，不做第三次弹窗。

## 6. 交互模型

### 6.1 选择

单击选、`Ctrl` 切换、`Shift` 区间、`Ctrl+A` 全选、`Esc` 清空。
右键点击未选中项时先改选择再弹菜单；点击已选中项不动选择。
类型选择（连打字母跳转）目前没有，补上——这是文件管理器里最低成本的高频动作。

### 6.2 导航

| 动作 | Win / Linux | macOS |
| --- | --- | --- |
| 后退 | `Alt+Left` | `Cmd+[` |
| 前进 | `Alt+Right` | `Cmd+]` |
| 后退（鼠标侧键） | 未接 | 未接 |
| 上一级 | `Alt+Up`、`Backspace` | `Cmd+↑` |
| 进入 | `Enter`、双击 | 同 |
| 快速预览 | `Space` | 同 |
| 地址编辑 | `Ctrl+L` | `Cmd+L` |
| 搜索 | `Ctrl+F` | `Cmd+F` |
| 命令面板 | `Ctrl+Shift+P` | `Cmd+Shift+P` |

单击目录不进入。拖到面包屑某一段 = 移动到该级（现有）。

### 6.3 键盘

每个可见动作都必须在命令面板里能被搜到，并显示同一个 chord。
现在的 `Shortcut.js` + Rust `shortcuts.rs` 已经支持重绑，界面只需要做到
"面板里显示的是用户当前绑定，不是默认值"。

### 6.4 命令面板

输入框在顶部（不是居中浮层），下面分组：导航 / 文件操作 / 视图 / 设置。
每行右侧显示 chord，`micro` `ink-faint`。无结果时给一条
`在文件内容中搜索 "xxx"` 的兜底动作，而不是空白。

## 8. 落地顺序

按"改动面 / 收益"排序，前四项做完界面就已经是另一个东西了。

1. **`Theme.qml` 单例 + 去硬编码。** 41 个文件里重复的 `textColor` /
   `mutedColor` / `hairline` / 圆角 / 字号全部指向单例。这是全局一致性的唯一根，
   也是一个 `pragma Singleton` 加 `qmldir` 的事。顺手修掉 `Segoe Fluent Icons`
   与 `Cascadia Mono` 的平台回退。
2. **顶栏合并 44 / 导航条 46 / 状态条 26。** 含 `window.h` 的 `kTitleBarDp`。
3. **导航历史栈。** Rust 侧 `Tab` 加环形缓冲，QML 加前后退钮与键位。
4. **行高 28/32/40、字号地板 11、圆角归一 4/6/12/16。**
5. 搜索框折叠 + 视图切换合并成一个按钮。
6. 状态条的传输折叠 + 预览宽度自适应。
7. 侧栏 216 + 容量条 + 拖放高亮。
8. 动效与 `reduceMotion`。

第 1、2、4 项不改变交互逻辑，可以独立提交；第 3 项需要动 Rust。

## 9. 验收

- 纵向外壳 = 116 px；四段变三段。
- 单屏字号 ≤ 4 档；全仓无 `pixelSize: 9` / `10`。
- 全仓硬编码 hex = 0（`grep -c '#[0-9a-fA-F]\{6\}' qml/*.qml`）。
- 圆角只出现 4 / 6 / 12 / 16。
- 一屏内 `interactive` 出现 ≤ 3 处。
- 每个动作都有键位，且命令面板里显示的是当前绑定。
- 键盘 Tab 走完整个窗口，焦点环始终可见。
- 文字对比度：`ink` ≥ 12:1，`ink-muted` ≥ 4.5:1，`ink-faint` 只做图标不做文字。
- 三平台截图并排：骨架尺寸、字号、行高一致，只有材质与窗口按钮不同。

# dae 界面规范（Qt 版，2026）

> 2026-10-28 起，颜色、字号、圆角与外壳几何的执行值以
> [`docs/ui-instrument-migration.md`](ui-instrument-migration.md) 为准。本文的 token、
> 几何、预览断点与验收口径已与该执行清单同步；迁移步骤与验证状态以该文件为准。

设计对象是 `qml/` 下的 41 个文件、19652 行，以及它要取代的 React 版视觉遗产
（`src/App.css`）。所有数字都是可实现的，不是示意图。

本文的取舍只有一条判据：**文件管理器的每一次操作都有明确的下一步，界面不该让人
找下一步在哪。**

### 1.1 迁移时先修的六个硬问题

不是审美问题，是功能或平台问题。六项均已落地，回归时按 §12 复查。

1. **导航历史。** 栈挂在 `Tab.qml`，每标签独立；`Alt+Left` / `Alt+Right` /
   `Backspace` 与 mac 的 `Cmd+[` / `Cmd+]` / `Cmd+↑` 已绑定。
2. **窗口按钮在 macOS / Linux 上的回退。** 不再依赖 `Segoe Fluent Icons`；
   Windows 用字体字形，mac 用红绿灯，Linux 用自绘形状。
3. **等宽字体平台栈。** 统一走 `Theme.monoFamily`，Windows Cascadia → Consolas，
   mac SF Mono → Menlo，Linux JetBrains Mono → DejaVu Sans Mono。
4. **图标统一来源。** 侧栏、标签、菜单、空状态统一用 `Glyph` / `ThemedIcon`，
   不再混用 unicode 字形和字体图标。
5. **字号地板 11 px。** 9 / 10 px 已删除；`font.pixelSize` 只出现 §3.2 的 8 档。
6. **行高对齐。** 28 / 32 / 40 与表头 28 / 32 / 36 成对，不再出现 34。

## 2. 定位

**内容占满窗口，外壳只在被需要时出现。**

三条硬约束，用来否决任何后续提案：

1. 视线起点是第一行文件名，不是顶栏。纵向外壳 ≤ **116 px**。
2. 一个窗口只有一种饱和色：信号橙。它不上背景、不上卡片、不上图标填充。
   例外只有报告性颜色：git 状态徽章（`warn` / `link`）、容量告警和危险操作。
3. 任何装饰必须能回答"它传达了什么状态"。答不上就删。

### 2.1 反面清单（这些会立刻把界面变成 2026 年的 AI 味）

- 玻璃拟态卡片、半透明面板叠半透明面板
- 紫色／靛蓝渐变当品牌色
- 24 px 大圆角药丸按钮、悬浮圆形主按钮
- 每个面板都带投影，形成三层阴影叠加
- 空目录里放插画
- 图标用 emoji 或双色填充
- 居中大标题 + 副标题的"欢迎"版式出现在工具软件里
- 行按 20 ms 错峰入场、骨架屏呼吸循环

## 3. 基础层

> 已落地：`qml/Theme.qml`（`pragma Singleton`，由 `qml/qmldir` 声明，
> `apps/dae/build.rs` 打进 qrc）。组件的颜色、字号、圆角、行高只引用该单例；
> 剩余字面量见 §3.1 末尾的允许例外。

### 3.1 颜色

**八位十六进制在 Qt 里是 `#AARRGGBB`，不是 CSS 的 `#RRGGBBAA`。** 写成
`#ffffff14` 会得到一个接近不透明的黄色，而且不报错、只是画出来。半透明白
必须写 `#14ffffff`。这一条值得单独记住，我在迁移里踩过一次。

材质色只在窗口骨架（chrome）上；内容面**必须不透明**。`chrome` 半透明时
用 `chromeTint`，系统不支持材质时回退到实色 `Theme.chrome`。

| Token | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| `canvas` | `#fbfbf9` | `#151619` | 列表、预览正文、内容面 |
| `canvasAlt` | `#f4f4f1` | `#1b1c20` | 次级内容面、成组区域 |
| `chrome` | `#efefec` | `#101114` | 标题栏、导航条、侧栏、状态条 |
| `raised` | `#ffffff` | `#202125` | 菜单、对话框、命令面板 |
| `field` | `#e9e9e5` | `#17181b` | 搜索框、路径编辑、重命名 |
| `ink` | `#161719` | `#ecedef` | 文件名、正文 |
| `inkMuted` | `#5c6066` | `#9ba0a8` | 次级信息、列头、状态 |
| `inkFaint` | `#646970` | `#8b9098` | 分组标签、弱提示；两套都 ≥4.5:1 |
| `hairline` | `#14000000` | `#16ffffff` | 结构线、未聚焦控件边 |
| `hairlineStrong` | `#25000000` | `#25ffffff` | 输入框、浮层、抬起面的边 |
| `hover` | `#0c000000` | `#0dffffff` | 指针悬停 |
| `fill` | `#12000000` | `#14ffffff` | 激活 chip、当前标签、菜单悬停 |
| `rowRule` | `#09000000` | `#0bffffff` | 列表行分隔；比 hairline 更轻 |
| `signal` | `#b45309` | `#f0a24a` | 全窗口唯一信号色 |
| `signalSoft` | `#1ab45309` | `#1af0a24a` | 选中行、激活菜单项 |
| `signalSoft2` | `#2eb45309` | `#29f0a24a` | 拖放边、搜索框聚焦底 |
| `onInteractive` | `#ffffff` | `#1b1306` | 信号色上的字 |
| `danger` | `#b42318` | `#f0918a` | 破坏性文字 |

| `warn` | `#9a6700` | `#e0a340` | 容量 >90%、冲突 |
| `success` | `#2f7d32` | `#8fd18f` | 完成态 |
| `link` | `#0969da` | `#6cb6ff` | 提交哈希、引用型信息 |
| `scrim` | `#1a181816` | `#61000000` | 模态遮罩 |

规则：

- 默认强调色是 `brand`（信号橙）；「系统强调色」仍保留在设置里。
  `Theme.brand` 与 `Theme.signal` 同值，`Theme.interactive` 按设置选择。
- `selection` 为信号色 10%（亮）/ 16%（暗）；`focusRing` 为 30%。
- 一屏内信号色最多 3 处：当前行左轨、焦点环、一个主按钮/激活 chip。
- 左侧当前行是 `signalSoft` 底 + 2 px `signal` 左轨，不用整行饱和填充。
- 状态永远"色 + 形状/字"双通道：错误带图标，成功带对勾，冲突带 `!`。
- 斑马纹删掉；用 `hover` 与 `selection` 分层。
- 文件类型图标全部单色；颜色只留给 git 状态小徽章（`M` 用 `warn`，`U` 用
  `link`）、容量告警和危险操作。
- 允许保留的字面量：网盘品牌色、代码高亮、mac 红绿灯、Windows 关闭按钮的
  `#c42b1c`、媒体井与终端底 `#0b0b0c`。它们不跟随主题，所以不进 Theme。

OK 平台 accent 取自 `Appearance.accent`。取不到时用表里的兜底值，不要自己发明
第三套。

### 3.2 字体

系统 UI 字体（`Qt.application.font`），不要指定族名。等宽另立一个平台族栈：

| 平台 | UI | 等宽 |
| --- | --- | --- |
| Windows | Segoe UI Variable Text → Segoe UI | Cascadia Mono → Consolas |
| macOS | SF Pro Text | SF Mono → Menlo |
| Linux | 系统 sans（fontconfig） | JetBrains Mono → DejaVu Sans Mono |

字号只允许以下 8 档，全部对应 `Theme.type*`：

| 角色 | px | 用途 |
| --- | --- | --- |
| `micro` | 11 | 列头、分组标签、快捷键、状态附件 |
| `caption` | 11.5 | 状态条、空状态提示、预览元数据标签 |
| `small` | 12 | 标签页、文件元数据、表格数字、菜单辅助 |
| `body` | 12.5 | 侧栏行、面包屑、菜单项、命令面板项 |
| `name` | 13 | 文件名、列表主行、对话框正文 |
| `emphasis` | 13.5 | 预览文件名、命令面板输入 |
| `title` | 14 | 预览/对话框标题 |
| `display` | 22 | 多选预览的计数；不要用于标题或空状态 |

- 11 px 是地板。禁止 9、10。
- 字重只用 Regular / Medium（400 / 500）；标题不要 Bold。
- 正文行高 1.45，标题 1.15。
- 数字列（大小、时间、计数、速率）加 `font.features: {"tnum": 1}`，右对齐。
  这是文件管理器里最容易被忽略、也最影响扫读的一处。
- 单屏字号不超过 4 档。

### 3.3 几何

间距只有 4 / 8 / 12 / 16 / 24 / 32。圆角只有四级：

| 级 | 值 | 用在 |
| --- | --- | --- |
| `xs` | 2 | 键帽、徽标、chip、行内小目标 |
| `sm` | 4 | 行、按钮、输入框、菜单项、标签 |
| `md` | 8 | 菜单、浮层、toast、预览挂载面 |
| `lg` | 12 | 对话框、命令面板 |

**已落地。** 原来的 4/6/12/16 收敛到 2/4/8/12。仍然写数字的只剩"胶囊"——
进度条、滚动条滑块、播放按钮，它们的圆角不是造型而是 `width / 2`、
`height / 2`，所以在代码里就是这么写的，不占四级。

行高 **28 / 32 / 40**（紧凑 / 默认 / 宽松），表头 **28 / 32 / 36**，与行高成对。
34 已退出——它不是 2 的倍数，和 32 的表头对不齐，滚动时行线会错半像素。

**字号地板 11 px 已落地。** 8/9/10 已删除，`font.pixelSize` 只出现 §3.2 的 8 档。
行图标 16 px，侧栏图标 14，菜单/面板图标 14，空状态 28，网格字形 38；绘制在
24 px 格子里（光学边距 4），列表行内与文字基线居中对齐。

点击目标最小 24×24；图标按钮的可点区域永远大于绘制区域。

### 3.4 材质与海拔

- 材质（Mica / Acrylic / vibrancy）只铺在 `chrome` 上；内容面永远实色。
- 海拔两级：内容面 0，浮层 1。浮层 = `raised` + `hairline-strong` 1px +
  阴影 `y2 blur12 8%`。面板不带投影，用 hairline 分隔。
- 全窗口只有一个"浮起来"的东西（菜单 / 对话框 / 命令面板之一）。

### 3.5 动效

| 动作 | 时长 | 曲线 |
| --- | --- | --- |
| hover / 选中 / 焦点 | 90–110 ms | OutQuad |
| 面板滑出、侧栏折叠 | 180 ms | OutCubic |
| 菜单、命令面板 | 160 ms（opacity + scale 0.97→1） | OutCubic |
| 视图切换（列表↔网格） | 200 ms，只动 opacity | OutCubic |

- 只动 `opacity` 与 `x/y`；不动 `width` / `height` / `anchors`（触发布局重算）。
- 禁止：列表行错峰入场、骨架屏呼吸以外的循环、按钮回弹。
- **已落地**：`Theme.motion`（= `!ExplorerPrefs.reduceMotion`）是所有 `Behavior`
  的统一开关，`Theme.motionFast/Panel/Overlay` 是三条时长。开启后是瞬时切换，
  不是变慢——"更快"仍然是动画。Qt 6 没有系统级媒体查询，开关在 `explorer.ini`。
- 目前的动效只有三处：搜索框展开（180 ms）、toast 淡入（160 ms）、菜单/面板
  淡入（160 ms）。隐藏一律瞬时——会淡出的菜单会吃掉下一次点击。

### 4.1 顶栏：标题与标签合并（44）

"dae" 这个标题对已经开着应用的人没有信息量，路径在导航条里，标签写的是目录名。
两行合并成一行，空白区就是拖窗区。

- **Windows**：三个按钮 46×44，悬停关闭 `#c42b1c`。`crates/dae-qt/cpp/window.h`
  里的 `kButtonDp = 46` 不变，`kTitleBarDp` 40 → 44。maximize 仍是
  `HTMAXBUTTON`，Snap Layouts 不受影响。标签条的空白区必须仍返回 `HTCAPTION`，
  否则撕标签时整个顶栏不能拖。
- **macOS**：红绿灯占左侧 78 px，标签从 x=86 起。不画自绘窗口按钮。顶栏
  双击行为交给系统。
- **Linux**：右上自绘三钮，风格与 Win 一致（GNOME/KDE 用户在 CSD 下预期如此）。
- **实现约束（已落地）**：标签条是顶栏里唯一必须保留为 client area 的一段。
  `window.h` 的命中测试把整条 44 当作 caption，只有 QML 通过
  `setCaptionClient(left, right)` 报上来的带区返回 `HTCLIENT`；否则点标签会变成
  拖窗口。改标签宽度/间距/起始位置时，这两处必须一起改。
- 「新窗口」按钮从标签条移走了 —— 它是这条 44 px 上唯一的空位，而空位是窗口的
  拖拽把手。同一个功能留在命令面板（`新建窗口`）。

标签：

- 高 32，上边距 6，间距 2，圆角 4（只圆上边）。
- 激活标签 `fill` 底 + `ink` 文字 + 底部 2 px `signal` 短线；非激活透明，
  hover `hover`。
- 关闭按钮只在激活或 hover 时出现——每个标签省 16 px，10 个标签就是 160 px。
- 宽 120–220，按内容自适应，超出 ellipsis 中间截断（`~/code/…/qml`）。
- 新标签 `+` 紧贴最后一个标签，不靠右。
- 撕标签：拖动 12 px 触发，被拖标签 60% 不透明，插入位置画 2 px 竖线（`signal`）。

### 4.2 导航条（44）

一条里按顺序：**后退 / 前进 / 上一级** · 面包屑（占满剩余）· 搜索按钮 · 视图切换。

- 后退/前进是本规范里唯一的新控件。**已落地**：栈挂在 `Tab.qml` 上而不是窗口上
  —— 标签就是浏览会话，撕裂到新窗口后后退键必须还在。两条栈各限 64 条，条目是
  `{ path, selected, anchor }`，所以回到历史位置时选中项也跟着回来。
  「新跳转清空前进栈」按浏览器语义处理；从一个面（回收站/空间/概览）跳进文件夹
  时不记栈，因为那时的 `listing.path` 已经不是用户看到的东西。
- `Alt+Left` 后退，`Alt+Right` 前进，`Alt+Up` / `Backspace` 上一级；macOS 用
  `Cmd+[` / `Cmd+]` / `Cmd+↑`。
- 前进/后退在栈空时**保留占位但降为 `hairline` 色**，不要隐藏——按钮位置跳动比
  按钮变灰更糟。鼠标侧键（`BackButton`/`ForwardButton`）还没接，是下一步。
- 面包屑每段 hover `hover`，当前段不加粗（加粗会让路径条在移动时抖动）。
  超出用 `…` 开祖先菜单。点空白进入路径编辑（现有行为保留）。
- 搜索：常驻 224 px 输入框改为图标按钮，点击展开为 210×28 输入框；有查询词时
  保持展开，`Esc` 清空并收回。`Ctrl+F` 直接展开。这条改动把导航条还给路径，
  也把"搜索"从背景噪音变回一个动作。
- 视图切换：单个按钮 + 菜单（列出/网格/分栏/概览），按钮图标显示当前视图。
  不做四段 seg control——Hick 定律，且窄窗口放不下。
- 内容搜索的选项条（`\u2022*` / `Aa` / 类型过滤）保留在导航条下方 30 px，
  只在内容搜索激活时出现，不做常驻。

### 4.3 状态条（28）

三段：左信息、中传输、右开关。

- 左：`N 项 · 已选 M 项` + 上下文（`搜索：resize · 12 项` / `回收站` / `sftp://host`）。
- 中：传输折叠成胶囊 `2 传输  ↻`，点击展开 326 px 浮层列表。每行：方向、文件名、
  进度条 2 px、速率、剩余、取消。
- 右：`main`（git 分支）、预览开关、终端开关。图标 16，激活态 `ink`，非激活
  `inkFaint`。
- 数字 `tnum`；等宽只用于协议名和速率。
- 状态文字用 UI 字体 12 px；只有 `sftp://` 这类技术串用 `Theme.monoFamily`。

### 4.4 侧栏（216）

216 能放下"新建空间"和长卷名；可拖 180–280，宽度记忆。

- 分组：`位置`（主目录 / 桌面 / 下载 / 文稿 / 图片）→ `卷`（带 2 px 容量条）→
  `空间` → `网络` → `云` → `回收站`。
- 行高 28，图标 16，缩进 14/级，展开箭头 12 px 且只在 hover 或展开时着色。
- 分组标题 11 `inkFaint`，大写间距 +0.02em，不折叠（文件管理器里折叠侧栏
  分组是给自己找麻烦）。
- 拖放目标：整行 `signalSoft` + `hairlineStrong`，不用描边框。
- 卷行右侧容量条：`2 px`，填充 `signal` 50%，超过 90% 转 `warn`。

## 5. 内容区

### 5.1 列表（主视图）

- 行高 28/32/40，表头 28/32/36（11 `inkFaint`，排序指示 4 px 三角）。
- 列：名称（`1fr`，min 220）/ 大小（右, 92）/ 类型（108）/ 修改时间（142）。
  窄屏依次丢类型、再丢大小与修改时间（现有 `showModified` 等逻辑保留）。
- 图标 16 在 24 格；缩略图 24（列表）/ 160（网格）。
- 选中：`signalSoft` 底 + 左侧 2 px `signal` inset bar。
- 焦点：**只在键盘操作时**画 1 px `signal` 内描边。鼠标点击只给选中态。
  这是"单击后行上出现一圈框"的根源，Qt 默认会给焦点框，要按输入原因过滤。
- hover `hover`，不改变文字色。
- 内联重命名：选中行直接可编辑，默认只选中主名不含扩展名。
- 空目录：一行 13 px `ink-muted`（`这个文件夹是空的`）+ 两个文字动作
  （`新建文件夹`、`粘贴`），不画插画，不居中。
- 加载：只在超过 300 ms 时出 8 条 hairline 脉冲行，宽度固定（避免宽度随机导致
  的反复重排）。

### 5.2 网格

按 `columns = max(1, floor((width - 32 + 12) / (100 + 12)))` 求列数，再均分剩余
宽度；tile 最小 100，间距 14×12，缩略图 4:3，文件名常显两行 ellipsis。
网格下不显示大小和类型（进预览面板）。选中态与列表一致（`signalSoft` +
1 px `signal` 内描边，圆角 4）。

### 5.3 分栏（Miller columns）

列宽 240–260，末列 flex。表头 32、行 32，每列 header 吸附，列间 1 px
`hairline`。`←` / `→` 跨列移动焦点并展开下一列。

### 5.4 预览面板

- 默认 300，可拖 260–420，双击恢复 300；6 px 拖拽缝，悬停 `signal`。
- 单文件：头（32 图标 + 文件名 13 `ink` + 类型 11 `inkMuted`）→ 缩略图或文本 →
  元数据 4 行 → `全部属性 ⌄`（原地展开，不完全替代 `PropertiesDialog`）。
- 多选：`3 项 · 1.2 MB` + 类型分布前 3。
- 目录：前 20 项 + `还有 342 项`。
- 文本用等宽 11，行高 1.6，行号默认关，代码块底色 `canvasAlt`、圆角 4。
- 媒体黑底、不描边、不留安全边距。

### 5.5 终端

高 132，内容区内嵌，不覆盖列表；标题栏 28（会话名 / 清屏 / 关闭）。
与预览面板可以并存——两个都是"看"的地方，互斥反而打断。

### 5.6 对话框

对话框共用一套骨架：`lg` 圆角 12；简单对话框 440 宽，数据型对话框沿用现有
功能宽度（属性 600）；标题 `title` 14、正文 13、底部 44、按钮 28 高且右对齐，
主按钮唯一。

- 遮罩用 `scrim`；点击遮罩关闭（破坏性确认除外）。
- 破坏性操作：主按钮 `danger` 色，文案动词化——`移到回收站`，不是`确定`。
- 覆盖冲突（`TransferConflictDialog`）：左旧右新并排，差异区高亮，
  `全部应用` 做成次要按钮加复选框，不做第三次弹窗。

## 6. 交互模型

### 6.1 选择

单击选、`Ctrl` 切换、`Shift` 区间、`Ctrl+A` 全选、`Esc` 清空。
右键点击未选中项时先改选择再弹菜单；点击已选中项不动选择。
类型选择（连打字母跳转）已落地——这是文件管理器里最低成本的高频动作。

### 6.2 导航

| 动作 | Win / Linux | macOS |
| --- | --- | --- |
| 后退 | `Alt+Left` | `Cmd+[` |
| 前进 | `Alt+Right` | `Cmd+]` |
| 后退（鼠标侧键） | 未接 | 未接 |
| 上一级 | `Alt+Up`、`Backspace` | `Cmd+↑` |
| 进入 | `Enter`、双击 | 同 |
| 快速预览 | `Space` | 同 |
| 地址编辑 | `Ctrl+L` | `Cmd+L` |
| 搜索 | `Ctrl+F` | `Cmd+F` |
| 命令面板 | `Ctrl+K` | `Cmd+K` |

单击目录不进入。拖到面包屑某一段 = 移动到该级（现有）。

### 6.3 键盘

每个可见动作都必须在命令面板里能被搜到，并显示同一个 chord。
现在的 `Shortcut.js` + Rust `shortcuts.rs` 已经支持重绑，界面只需要做到
"面板里显示的是用户当前绑定，不是默认值"。

### 6.4 命令面板

输入框在顶部（不是居中浮层），下面分组：导航 / 文件操作 / 视图 / 设置。
每行右侧显示 chord，`micro` `inkFaint`。无结果时给一条
`在文件内容中搜索 "xxx"` 的兜底动作，而不是空白。
